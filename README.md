# Atividades de Python

Repositório destinado às atividades desenvolvidas na disciplina de Desenvolvimento em Python.

## Atividades

### Terceira semana

Foram desenvolvidos exercícios focados em modularização e organização de código, utilizando funções, parâmetros, retorno, escopo e criação de módulos.

* Módulo de calculadora
* Módulo de utilidades
* Script principal com importação de módulos
* Conversor de temperatura
* Validador de senha
* Caixa com múltiplos preços
* Ficha do aluno
* Lista segura com cópia defensiva
* Versões equivalentes em Portugol

## Tecnologias utilizadas

* Python 3
* Portugol
* Visual Studio Code
* Git e GitHub
